广东实验中学（荔湾校区）Minecraft 地图（Java 版 26.3）

【安装】
把 gdsy-campus 整个文件夹放进存档文件夹 saves：
  按 Win+R，输入 %appdata%\.minecraft\saves 回车，把文件夹拖进去。
进游戏 → 单人游戏 → “广东实验中学（荔湾校区）”。
（存档由官方 26.3 服务器生成并加载检查过。比 26.3 新的版本也能打开，会自动升级。）

【进去以后】
出生在校门外，面朝西就是校门。创造模式，双击空格飞行；固定中午，不刷怪、不下雨。
一格 = 1 米，坐标和 3D 版一致（x 向东，z 向南）。传送：
  /tp 262 64 -20    校门外            /tp 236 64 -20    水池前
  /tp 170 64 -81    网架广场          /tp 195 64 -55    钟楼下
  /tp 0 64 0        操场中央          /tp -19 64 0      看台前
  /tp 87 65 46      篮球场            /tp 83 65 -14     体育馆内
  /tp 165 64 -121   弧形楼前          /tp 200 64 -150   弧形楼与新综合楼之间
  /tp 190 64 60     宿舍区            /tp 38 64 150     南边一带
想恢复昼夜：/gamerule advance_time true

每一版做了什么、还差什么，见 GitHub 仓库里的 minecraft/README.md。
