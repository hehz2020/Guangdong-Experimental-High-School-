# 广东实验中学（荔湾校区）3D 校园漫游

**状态：开发中，目前是「测绘校验版」，不是复原成品。**

现在打开看到的是按卫星影像量出的建筑平面轮廓，以统一高度的灰色方块表示，可以用第一人称在其间行走。楼的高度、外立面、室内、光影都还没有做。

## 运行

仓库已包含运行所需的全部文件，无需安装依赖，也不访问任何外部网络。用任意静态文件服务器打开即可：

```
npm start          # 等价于 python3 -m http.server 8080
```

然后用**电脑浏览器**访问 `http://localhost:8080/`。点击画面开始，W A S D 或方向键移动，鼠标转向，Shift 跑，Esc 释放鼠标。

手机暂不可用：触屏操控尚未完成。

## 目前有什么

| 内容 | 情况 |
|---|---|
| 坐标系 | 原点在田径场中心（约 113.22149°E, 23.076014°N），x 向东、z 向南，单位米 |
| 田径场 | 实测。跑道外沿约 90.6 × 160.1 米，草皮约 71.4 × 109.3 米。形状是两端浅弧的圆角矩形，**不是标准 400 米跑道**，圈长未能确定（粗估 340–350 米）。目前画面里仍画成直角矩形 |
| 建筑轮廓 | 10 个条目，见 `src/campus-data.js`。每个条目都记录了量测来源、误差估计和可信度 |
| 行走与碰撞 | 按轮廓做二维碰撞，可贴墙滑动。广场网架顶棚下方可以穿行 |

`src/campus-data.js` 中的可信度分三类：

- **视频已证实**：看台、体育馆、广场网架顶棚。
- **仅卫星图可见**：弧形大楼、圆形穹顶等。它们是否属于学校、作何用途，均未证实。
- **只读过一次**：个别小构件，未经复核。

## 还没有、或不可靠的部分

- **楼高全部是占位值**（统一 12 米），没有任何实测或估算高度。
- **外立面、屋顶造型、钟楼**尚未建模。钟楼在卫星图上未能定位。
- **室内没有任何参考资料**。将来若加入室内，只能是推测，会明确标注。
- **校园边界未确认**。弧形楼以北和南端建筑群是否属于学校并不清楚。
- **光影**只有一个随手放置的方向光，不是成品效果。
- 篮球场、宿舍、东侧教学楼、河涌与道路等尚未入库。

## 验证情况

以下均在无头浏览器（软件渲染）中验证，**没有在真实显卡或真实设备上测试过**：

- 行走与碰撞：7 个按数据预先算出预期位置的用例。
- 键盘输入、鼠标锁定与释放的界面流程、窗口尺寸变化。
- 鼠标转向的处理逻辑（幅度与方向）。

未能验证的：

- 真实鼠标在真实浏览器中的转向（测试环境中合成的鼠标移动净位移为零，只验证了处理逻辑）。
- Esc 键释放鼠标（测试中是用脚本触发释放的）。
- 帧率。软件渲染下的表现不代表真实显卡。

已知现象：抗锯齿与阴影同时开启时，无头软件渲染环境的控制台会出现 4 条图形驱动的性能提示（`GPU stall due to ReadPixels`），不是错误。成因未查明，真实显卡上是否出现未测试。

## 校验用的网址参数

- `?view=top` 正上方俯视（北在上）；可加 `&w=&e=&n=&s=` 指定范围（米），用于与卫星图逐像素对齐
- `?view=overview` 斜俯视
- `?flat=1` 轮廓以纯色无阴影绘制
- `?aa=0`、`?shadows=0` 关闭抗锯齿、阴影（排查用）

## 资料来源

- **卫星影像**：Esri World Imagery，第 19 级（约 0.27 米/像素）。仅用于量取平面尺寸，影像本身不包含在仓库中。
- **参考视频**：《省实2018军训—砺剑》，GEHA航空社发布于哔哩哔哩（BV1JW411D7Xc）。仅作外观参考，视频及截图均不包含在仓库中。画面为 2018 年、360p，据此得出的任何层数或细节都只是估计。
- **建筑名称**：来自公开的百科与新闻资料，尚未与具体轮廓一一对应。
