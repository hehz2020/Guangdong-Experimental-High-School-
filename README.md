# 广东实验中学（荔湾校区）3D 校园漫游

**状态：开发中，非官方复原，与学校无隶属关系。**

可以用第一人称在校园里行走：标准 400 米田径场、看台、体育馆（可进入）、篮球场、东侧两栋教学楼（可上楼、进教室）、钟楼、网架广场、校名墙、弧形楼、天文台圆顶、新综合教学楼、东南侧板楼等。电脑用键鼠，手机用屏幕摇杆。

所有位置来自一张斜拍卫星图的量测，所有楼高来自视频里的层数估算，都不是实测；很多细节是推测。详见下文。

## 运行

仓库已包含运行所需的全部文件，无需安装依赖，也不访问任何外部网络。用任意静态文件服务器打开即可：

```
npm start          # 等价于 python3 -m http.server 8080
```

然后用**电脑浏览器**访问 `http://localhost:8080/`。点击画面开始，W A S D 或方向键移动，鼠标转向，Shift 跑，Esc 释放鼠标。

手机暂不可用：触屏操控尚未完成。

## 目前有什么

| 内容 | 情况 |
|---|---|
| 坐标系 | 原点在田径场中心（约 113.221491°E, 23.075954°N），x 向东、z 向南，单位米 |
| 田径场 | **标准 400 米、8 道**。草皮在卫星图上实测 71.4 × 109.3 米；跑道外沿用 2022 年体育节视频的正俯视画面、以草皮为标尺量得 177.2 × 92.2 米，与标准跑道（176.91 × 92.52 米）相差不到 0.3 米，故按标准几何建模 |
| 建筑 | 39 个条目，原始量测见 `data/measurements.json`，推导出的地面坐标见 `src/campus-data.js`（由 `npm run data` 生成）。每个条目都记录了量测来源、高度估算依据、位置误差和可信度 |
| 行走与碰撞 | 胶囊体对八叉树的三维碰撞，有重力和跳跃，可贴墙滑动；广场网架顶棚下方可以穿行 |
| 光照 | 按时刻计算太阳方位的基础版（`?time=17.5` 可改时刻），尚未调校 |

### 两个必须知道的前提

1. **卫星图是斜拍的。** 影像从北偏东方向拍摄，屋顶在图上相对地基向南偏西位移，每米高度约 0.63 米。因此图上量到的是屋顶轮廓，地面位置需按楼高反推。位移系数是用教学楼可见的北立面宽度对估计楼高标定的，没有独立标定，范围约 ±17%。
2. **所有楼高都是估计值。** 没有任何实测高度；层数来自视频画面，层高统一假定为 3.9 米。高度估错会连带影响地面位置：20 米高的楼，高度每错 1 米，位置约错 0.6 米。

`src/campus-data.js` 中每个条目的 `positionAccuracyM` 已把这两项不确定性合并进去（多数在 ±2 至 ±4 米）。

可信度分三类：**视频已证实**；**仅卫星图可见**（是否属于学校、作何用途未证实）；**单次读数，待复核**（东侧教学区的 18 个条目来自一个测量代理的单次读数，独立复核尚未完成）。

## 还没有、或不可靠的部分

- **推测的内容**（各生成器文件顶部的 ASSUMED 注释逐项列出）：教学楼的南侧外廊、全部教室布置和楼梯位置；体育馆的全部室内；各楼看不到的背立面；战斗机的机型、朝向和升旗台的位置；校徽是按文字描述画的近似图形。
- **新综合教学楼**只是简化体块：轮廓是单次读数，分不清裙楼和主楼；视频里的格栅、门洞、露台和图书馆室内都还没有做。它的 6 层来自规划文件，是本项目唯一有官方来源的层数。
- **校园边界未确认**。南端建筑群、北区其余建筑、校门、道路和绿化尚未入库；树木只有零星几处。
- **独立复核没有完成**：原计划对东侧教学区、东南板楼、球场各做一次独立重测，因用量上限没有跑成，这些条目都是单次读数。
- **钟楼**位置是单次读数（±3.6 米），高度约 40 米是粗估。
- 教室、走廊没有任何参考资料；图书馆室内有参考（2022 年视频）但尚未建模。

## 验证情况

以下均在无头浏览器（软件渲染）中验证，**没有在真实显卡或真实设备上测试过**：

- 行走与碰撞：10 个用例，预期值由数据文件推导。
- 教学楼：从地面进外廊、走楼梯上二层、穿过教室门进入教室（两栋都测过）。
- 界面：小地图、时间滑块、鼠标锁定与释放的流程、鼠标转向的处理逻辑。
- 手机触屏：在设备模拟下，推摇杆前进、右半屏滑动转向、松手停止。只在轻量场景下测得动，因为这里软件渲染全校园在手机像素密度下每秒不到一帧。

未能验证的：真实鼠标和 Esc 键、任何真机上的触屏、真实设备上的帧率（全校园约 70 万三角形，手机上是否流畅未知）。

已知现象：抗锯齿与阴影同时开启时，无头软件渲染环境的控制台会出现 4 条图形驱动的性能提示（`GPU stall due to ReadPixels`），不是错误。成因未查明，真实显卡上是否出现未测试。

## 校验用的网址参数

- `?view=top` 正上方俯视（北在上）；可加 `&w=&e=&n=&s=` 指定范围（米）
- `?view=overview` 斜俯视；可加 `&cx=&cy=&cz=&tx=&ty=&tz=` 指定相机位置与目标
- `?flat=1` 实体轮廓以纯色无阴影绘制
- `?time=15` 时刻（小时）；`?aa=0`、`?shadows=0` 关闭抗锯齿、阴影；`?quality=low|high` 画质；`?ui=0` 隐藏界面；`?only=编号,编号` 只生成指定建筑
