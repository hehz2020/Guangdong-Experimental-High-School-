# 广东实验中学（荔湾校区）3D 校园漫游

**状态：开发中，非官方复原，与学校无隶属关系。**

可以在校园里行走或飞行：标准 400 米田径场、看台（可上）、体育馆（可进入）、八块篮球场、东侧两栋教学楼（五层都能走上去，教室和办公室可进）、西侧教学楼（五层的教室、实验室、办公室都可进）、钟楼、网架广场、校名墙、弧形楼、天文台圆顶、新综合教学楼（底层图书馆可进）、东南侧板楼和圆塔、战斗机、升旗台，以及约 700 棵树、校内道路和东侧河涌；校园周边的 14 组建筑也有了体量模型。时间可调，从清晨到有星星的夜晚。

所有位置来自一张斜拍卫星图的量测，所有楼高来自视频里的层数估算，都不是实测；很多细节是推测。详见下文。

## 校门与水池：写实小样

从这一版起，漫游从**校门**开始（网址加 `?start=field` 仍从田径场开始）。校门和门后的水池是按“好看、写实优先，比例和事实不必严格”的要求做的一块小样，用来确定之后整体画面的标准；校园其余部分还是之前的简化风格。

- **依据**：一张校门照片（从门前广场向西拍）。照片里钟楼露出的是东立面、正前方远处是体育馆东立面，据此把校门放在校园东侧临河涌的路上（约 x 247、z −20），卫星图上该处也有两个相隔约 16 米的浅色小屋顶。
- **按照片做的**：两座对称的白色门亭（外侧石墩、绿色玻璃间、不锈钢圆柱和暗红色柱础、向内悬挑并逐渐变薄的雨篷、雨篷尖上挂的红灯笼）、不锈钢推拉门、门前的锥形路障和白色花箱、右侧带白色压顶的红色校名墙（深色字、下方一行小号英文）、墙前的球形灌木和小彩旗、中间浅色两侧红褐色的广场铺地。
- **想象的**：所有尺寸；水池本身（只知道门后有水池）：圆形水池、刻校训的景石、喷泉、池前的弧形花台；通向体育馆的林荫道；全部树木花草、长椅、路灯；门前的马路和河涌边的步道；南侧的玻璃小屋。景石上的“爱国 团结 求实 创新”是学校公开的校训，但“刻在这块石头上”是编的。推拉门照片里是关着的，这里画成半开，好让人走进去。
- **画面上新用的做法**：用代码生成的带法线和粗糙度贴图的材质（石材、铺地、沥青、不锈钢、草地）；每块玻璃略有不同的倾角并带一层画上去的天空和树影；水面是真实的镜面反射加波纹；喷泉是按抛物线运动的水滴；阔叶树、大王椰、南洋杉式的高树和花坛都由带镂空叶片的小面片组成，会随风轻微摆动。全部由代码生成，没有使用任何照片或外部素材。
- **没有做到的**：这不是虚幻引擎那种级别的画面；校名用的是系统里的毛笔或楷体字体（没有就退回普通字体），不是真实校名的题字；只在无头软件渲染里看过。

## 运行

仓库已包含运行所需的全部文件，无需安装依赖，也不访问任何外部网络。用任意静态文件服务器打开即可：

```
npm start          # 等价于 python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

### 一键启动程序（可选）

不想装 Python 的话，可以把整个站点编进一个可执行文件：`launcher/` 里是一个只用 Go 标准库写的小程序（约 100 行），
`sh launcher/build.sh` 会把当前的 `index.html`、`src/`、`vendor/` 嵌进去，生成 Windows（`.exe`）、macOS 和 Linux 的版本
（放在 `launcher/dist/`，不进仓库；需要 Go 1.20 以上，不下载任何依赖）。双击后它只在本机 `127.0.0.1` 上提供这些文件，
不安装、不写盘、别的机器访问不到；关掉它的命令行窗口即退出。它不带浏览器，画面仍由你电脑上的浏览器渲染：Windows 上
如果在常见位置找到 Chrome 或 Edge，会开一个没有地址栏的独立窗口（`--app` 方式），否则（或加 `-tab` 参数）用默认浏览器开一个标签页；
macOS 和 Linux 上用默认浏览器。生成的程序没有数字签名，Windows 首次运行会弹出“已保护你的电脑”的提示，需要点“更多信息 → 仍要运行”。
Windows 和 macOS 版是在 Linux 上交叉编译的，**没有在这两个系统上实际运行过**（包括 Windows 上开独立窗口的那段）；同一份代码的
Linux 版试过：文件类型正确，只监听本机，无头浏览器能从它完整加载页面（没有构建失败和报错）。

### 两个必须知道的前提

1. **卫星图是斜拍的。** 影像从北偏东方向拍摄，屋顶在图上相对地基向南偏西位移，每米高度约 0.55 米（2.0 像素）。因此图上量到的是屋顶轮廓，地面位置需按楼高反推。这个系数由一次独立的第二遍量测重新标定：四个教学楼北立面上，从女儿墙顶到二层楼板线是 33 至 35 像素，楼层线间距 7.4 至 8.0 像素。直接量到的其实是“五层楼的屋顶位移约 41 像素”；把它拆成楼高和每米位移，仍然依赖假定的 3.9 米层高。最初用的系数是 2.3（来自一条约 47 像素的立面带，其中包含了底层以下一段范围靠猜的暗区），偏大约 15%，使所有楼的地面位置偏北 1 至 2 米，现已改正。
2. **所有楼高都是估计值。** 没有任何实测高度；层数来自视频画面，层高统一假定为 3.9 米。高度估错会连带影响地面位置：20 米高的楼，高度每错 1 米，位置约错 0.6 米。

`src/campus-data.js` 中每个条目的 `positionAccuracyM` 已把这两项不确定性合并进去（多数在 ±2 至 ±4 米）。

可信度分三类：**视频已证实**；**仅卫星图可见**（是否属于学校、作何用途未证实）；**单次读数**。第二遍独立量测覆盖了 21 个主要轮廓（教学区、体育馆、看台、宿舍楼、弧形楼、圆顶、球场）：14 个与原读数一致（多数相差 1 至 5 像素），7 个有出入，其中 5 个已按第二遍读数改正（见下文“中途更正过的事实”），弧形楼屋顶和钟楼位置两项还在处理。没有复核的：教学楼两端的小楼、宿舍连接体、西教学楼的附属体、新综合教学楼、地面多边形。

## 还没有、或不可靠的部分

- **推测的内容**。每个生成器文件（`src/world/builders/`、`src/world/extras/`）顶部都有一段说明，分开列出「参考里看得到的」和 ASSUMED（推测的）。主要的推测有：东侧教学楼的南侧外廊、楼梯位置、房间划分和全部室内；西侧教学楼的北立面和楼内楼梯；体育馆的全部室内；看台和体育馆的所有尺寸（按视频画面比例估的，看台实物可能比模型高约一半）；弧形楼的北立面；板楼的南立面和圆塔的全部立面；战斗机的机型、朝向和升旗台的位置；校徽是按画面画的简化图形。
- **校名墙的位置和高度**：视频显示校名高出北教学楼屋顶，据此把字墙画到 26.4 米，立在连接体的北沿。第 6 帧里这面墙向西接着北教学楼南侧的高女儿墙，所以它更可能立在北教学楼屋顶的东南角，比现在的位置偏北约 3.7 米；没有改。
- **新综合教学楼**的轮廓是单次读数，而且卫星图拍摄时这栋楼还没建成（原址是旧楼），所以轮廓只能当近似；它的 6 层来自规划文件，是本项目唯一有官方来源的层数。上面四层是封闭的，没有室内。
- **校园边界未确认**。南端和北区的建筑现在有了体量模型，但哪些属于学校不清楚；校门没有做；看台以西在卫星图上是工地，没有建；西北角的两块网球场和东北角的一块硬地球场是否属于学校不清楚。绿化和铺地的量测范围南到 z = 150 米、北到约 −250 米，范围以外的周边建筑脚下只有一块示意性的铺地或裸地。
- **钟楼**的位置是重新定位过的（见“中途更正过的事实”），把握中等，约 ±1.5 米；东西向的进深最不确定。高度约 41 米（±3 米），取决于“教学楼女儿墙高 20.7 米”这个假定。塔头在挑台上的东西位置、西面那个浅色圆盘是什么，都没有查明。
- **南端那栋高层（约 75 米）只在卫星图上有。** 图上它的北立面有约 150 像素长、方向与斜拍完全一致的竖线，所以按 75 米建了；但 2018 年视频朝那个方向看是空的天。要么它是 2018 年 9 月之后建的，要么是读图有误。它从全校园都看得到，如果不对会很显眼。
- **钟楼西侧那栋五层楼的底层**画成了架空的柱廊。没有任何参考能看到它的底层，这样画是为了不堵住从南面进网架广场的路；实际可能是封闭的。
- **广场东北角的弧形台阶和一个暗红色门框**（2018 年视频第 8 帧）没有做。
- **三栋教学楼的南墙线没有定论。** 卫星图上屋顶南侧有一条明亮的女儿墙线，再往南 2 至 3 米还有一条较暗的窄带，数据取的是窄带外沿（进深约 13.5 米）。如果墙其实在女儿墙线下面（窄带只是走廊上方的挑檐），这三栋楼南侧就深了 2 至 3 米、教室也相应偏深。从图上分不出来，视频也看不到南面。

### 中途更正过的事实

- 跑道是标准 400 米（最初按卫星图误读为不足 400 米：南弯道在树影里）。
- 卫星图是斜拍的，最初量的屋顶轮廓被当成了地面轮廓，已全部校正。
- 看台座席是蓝、红、绿三段，不是全蓝（把 2022 年画面里的蓝色遮阳棚误认成了座席）。
- 西侧教学楼的玻璃楼梯塔在西端南侧，不在东端。
- 教学楼西侧的连廊不是 4 米高的平地连廊，而是约 7.8 米高的架空走道。
- 网架顶棚东南角那块蓝灰色不是缺口，是钟楼的影子。
- 斜拍系数由每米高度 2.3 像素改为 2.0 像素（见上文前提 1），所有建筑随之南移约 1.7 米。
- 西侧教学楼进深约 13.6 米、长 47.8 米，不是 17 × 51 米：最初把图上屋顶北侧带楼层线的暗色条带（其实是北立面）当成了屋顶，北边线因此偏北了 9 米。
- 看台座席比最初量的长 8 米：原来的南端其实是一道树影的边缘。三段颜色（蓝、红、绿）几乎等长。
- 网架顶棚南沿多出 2.1 米；体育馆整体东移 1.9 米；圆顶中心南移 1.9 米。
- 东侧教学楼两端楼梯塔的高度由 23.5 米改为 21.5 米（视频里塔顶板只比教学楼女儿墙高约 0.8 米）。
- **钟楼向南移了约 6.4 米。** 原来记下的那个方块其实是玻璃楼梯间屋顶上的浅色构件，不是钟楼。新位置有三条互相独立的依据：对 2018 年视频一帧做相机反算，塔身整个在网架南沿以南；卫星图上一条细长的亮带是玻璃楼梯间顶部和塔身下段被太阳照亮的东立面；按图上的太阳方位，41 米高的塔的影子正好落在网架屋面东南角那块蓝灰色斑上（之前以为是屋面缺口）。钟楼紧贴玻璃楼梯间南面，离南教学楼西端约 6.5 米，中间是连廊。
- 钟楼旁的玻璃楼梯间比原来记的大：约 7 × 8.4 米、玻璃顶约 24 米；西教学楼西端玻璃楼梯塔的北边线南移了 3.3 米。

## 验证情况

以下均在无头浏览器（软件渲染）中验证，**没有在真实显卡或真实设备上测试过**：

- 行走与碰撞：10 个用例，预期值由数据文件推导。
- 键盘：在真实的游戏循环里（界面开着）按键：W 行走、Shift 加速、空格跳、F 进出航拍、航拍中空格上升和 C 下降，共 9 项。
- 东侧两栋教学楼：从地面进外廊、走楼梯逐层上到五层、穿过教室门进入二层和五层的教室。
- 西侧教学楼：从地面进外廊、一口气走楼梯到五层、五层各进出一间房、助跑跳撞栏杆不会翻出去，共 18 项。
- 教学楼两端和小楼：12 栋每栋从四面走不进去、从上方落下停在屋顶，共 24 项。

## 校验用的网址参数

- `?view=top` 正上方俯视（北在上）；可加 `&w=&e=&n=&s=` 指定范围（米）
- `?view=overview` 斜俯视；可加 `&cx=&cy=&cz=&tx=&ty=&tz=` 指定相机位置与目标
- `?flat=1` 实体轮廓以纯色无阴影绘制
- `?start=地点名` 从 `gate.js` 提供的某个地点开始（默认「校门」），`?start=field` 从田径场开始；`?time=9.2` 时刻（小时，默认上午 9 点多：太阳在东边，照亮校门正面）；`?aa=0`、`?shadows=0`、`?post=0` 关闭抗锯齿、阴影、后期效果（`?post=1` 强制开启）；`?quality=low|high` 画质；`?adapt=0|1` 关闭或强制开启自动画质；`?safe=1` 安全模式；`?cascades=1|2|3` 阴影层数；`?ui=0` 隐藏界面；`?only=编号,编号` 只生成指定建筑（同时略去绿化、球场等附加模块，加 `&extras=1` 保留）
