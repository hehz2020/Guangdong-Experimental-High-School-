# 广东实验中学（荔湾校区）3D 校园漫游

**状态：开发中，不是复原成品。**

现在打开看到的是按卫星影像量出、并按视频估算高度的建筑体块，配有标准 400 米田径场，可以用第一人称在其间行走。外立面细节、室内和最终光影都还没有做。

## 运行

仓库已包含运行所需的全部文件，无需安装依赖，也不访问任何外部网络。用任意静态文件服务器打开即可：

```
npm start          # 等价于 python3 -m http.server 8080
```

然后用**电脑浏览器**访问 `http://localhost:8080/`。点击画面开始，W A S D 或方向键移动，鼠标转向，Shift 跑，Esc 释放鼠标。

手机暂不可用：触屏操控尚未完成。

## 目前有什么

| 内容 | 情况 |
|---|---|
| 坐标系 | 原点在田径场中心（约 113.221491°E, 23.075954°N），x 向东、z 向南，单位米 |
| 田径场 | **标准 400 米、8 道**。草皮在卫星图上实测 71.4 × 109.3 米；跑道外沿用 2022 年体育节视频的正俯视画面、以草皮为标尺量得 177.2 × 92.2 米，与标准跑道（176.91 × 92.52 米）相差不到 0.3 米，故按标准几何建模 |
| 建筑 | 28 个条目，原始量测见 `data/measurements.json`，推导出的地面坐标见 `src/campus-data.js`（由 `npm run data` 生成）。每个条目都记录了量测来源、高度估算依据、位置误差和可信度 |
| 行走与碰撞 | 胶囊体对八叉树的三维碰撞，有重力和跳跃，可贴墙滑动；广场网架顶棚下方可以穿行 |
| 光照 | 按时刻计算太阳方位的基础版（`?time=17.5` 可改时刻），尚未调校 |

### 两个必须知道的前提

1. **卫星图是斜拍的。** 影像从北偏东方向拍摄，屋顶在图上相对地基向南偏西位移，每米高度约 0.63 米。因此图上量到的是屋顶轮廓，地面位置需按楼高反推。位移系数是用教学楼可见的北立面宽度对估计楼高标定的，没有独立标定，范围约 ±17%。
2. **所有楼高都是估计值。** 没有任何实测高度；层数来自视频画面，层高统一假定为 3.9 米。高度估错会连带影响地面位置：20 米高的楼，高度每错 1 米，位置约错 0.6 米。

`src/campus-data.js` 中每个条目的 `positionAccuracyM` 已把这两项不确定性合并进去（多数在 ±2 至 ±4 米）。

可信度分三类：**视频已证实**；**仅卫星图可见**（是否属于学校、作何用途未证实）；**单次读数，待复核**（东侧教学区的 18 个条目来自一个测量代理的单次读数，独立复核尚未完成）。

- **室内**尚未建模。有参考的只有新图书馆大厅（2022 年视频）；教室、走廊没有任何参考资料，将来若加入只能是推测，会明确标注。

## 验证情况

以下均在无头浏览器（软件渲染）中验证，**没有在真实显卡或真实设备上测试过**：

- 行走与碰撞：10 个用例，预期值由数据文件推导（直行、横移、撞墙停住、贴墙滑动、顶棚下穿行、圆形建筑、跳跃、高处落地）。
- 键盘输入、鼠标锁定与释放的界面流程、窗口尺寸变化、鼠标转向的处理逻辑。

未能验证的：

- 真实鼠标在真实浏览器中的转向（测试环境中合成的鼠标移动净位移为零，只验证了处理逻辑）。
- Esc 键释放鼠标（测试中是用脚本触发释放的）。
- 帧率。软件渲染下的表现不代表真实显卡。

已知现象：抗锯齿与阴影同时开启时，无头软件渲染环境的控制台会出现 4 条图形驱动的性能提示（`GPU stall due to ReadPixels`），不是错误。成因未查明，真实显卡上是否出现未测试。

## 校验用的网址参数

- `?view=top` 正上方俯视（北在上）；可加 `&w=&e=&n=&s=` 指定范围（米）
- `?view=overview` 斜俯视；可加 `&cx=&cy=&cz=&tx=&ty=&tz=` 指定相机位置与目标
- `?flat=1` 实体轮廓以纯色无阴影绘制
- `?time=15` 时刻（小时）；`?aa=0`、`?shadows=0` 关闭抗锯齿、阴影（排查用）
