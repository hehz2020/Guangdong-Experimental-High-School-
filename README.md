# 广东实验中学（荔湾校区）3D 校园漫游

**状态：开发中，非官方复原，与学校无隶属关系。**

可以在校园里行走或飞行：标准 400 米田径场、看台（可上）、体育馆（可进入）、八块篮球场、东侧两栋教学楼（可上楼、进教室）、西侧教学楼（可走外廊和楼梯）、钟楼、网架广场、校名墙、弧形楼、天文台圆顶、新综合教学楼、东南侧板楼和圆塔、战斗机、升旗台。

所有位置来自一张斜拍卫星图的量测，所有楼高来自视频里的层数估算，都不是实测；很多细节是推测。详见下文。

## 运行

仓库已包含运行所需的全部文件，无需安装依赖，也不访问任何外部网络。用任意静态文件服务器打开即可：

```
npm start          # 等价于 python3 -m http.server 8080
```

然后访问 `http://localhost:8080/`。

| | 电脑 | 手机 / 平板 |
|---|---|---|
| 开始 | 点击画面（锁定鼠标） | 点一下屏幕 |
| 移动 | W A S D 或方向键，Shift 跑，空格跳 | 左下摇杆，「跑」「跳」按钮 |
| 转向 | 鼠标，Esc 释放 | 在右半屏滑动 |
| 航拍模式 | F 切换；朝视线方向飞，空格上升，C 下降 | 「航拍」按钮；「跳」为上升 |
| 直接前往某处 | 底部「地点」（先按 Esc） | 底部「地点」 |

上方滑块调整一天中的时间，右上角是小地图（北在上）。「地点」里有二层教室、体育馆内和两个空中机位；校名墙朝北、被教学楼挡着，在地面上看不到，要从「航拍：校名墙」看。

## 目前有什么

| 内容 | 情况 |
|---|---|
| 坐标系 | 原点在田径场中心（约 113.221491°E, 23.075954°N），x 向东、z 向南，单位米 |
| 田径场 | **标准 400 米、8 道**。草皮在卫星图上实测 71.4 × 109.3 米；跑道外沿用 2022 年体育节视频的正俯视画面、以草皮为标尺量得 177.2 × 92.2 米，与标准跑道（176.91 × 92.52 米）相差不到 0.3 米，故按标准几何建模 |
| 建筑 | 39 个条目，原始量测见 `data/measurements.json`，推导出的地面坐标见 `src/campus-data.js`（由 `npm run data` 生成）。每个条目都记录了量测来源、高度估算依据、位置误差和可信度 |
| 行走与碰撞 | 胶囊体对八叉树的三维碰撞，有重力和跳跃，可贴墙滑动；广场网架顶棚下方可以穿行 |
| 绿化与地面 | 约 700 棵树、草坪、铺地、三条校内道路、东侧河涌及两岸树，由 `scripts/make-landscape.py` 从卫星图分类得出（记录在 `data/landscape.json`）。树的位置对应图上的树冠团块，经独立脚本检查：没有树落在建筑、跑道、球场、道路或河涌里。草坪与铺地的划分只是对一张偏暗的斜拍图做颜色分类，未经其他来源核对；球场南侧那条路是从两排树冠之间的空隙**推断**的，路面本身看不到；远处的高层住宅和地铁车辆段只是示意背景，**未经量测** |
| 新综合教学楼与图书馆 | 外观按 2022 年视频：灰色石材基座、陶红色上部、西角门洞、屋顶校名、南面玻璃门厅、室外楼梯和露台。底部两层是图书馆，可从南面玻璃门走进去，上楼梯到二层回廊。图书馆是全项目唯一有真实室内参考的空间（2022 年视频），但具体平面布置仍是推测 |
| 性能 | 同一材质的几何体合并绘制；教室家具只在走近时显示，远看全校园约 36 万三角形。触屏设备默认降低像素密度和阴影分辨率（`?quality=high` 可强制提高） |
| 光照 | 按时刻计算太阳方位，天空、阳光颜色和曝光随时间变化（界面滑块或 `?time=17.5`） |

### 两个必须知道的前提

1. **卫星图是斜拍的。** 影像从北偏东方向拍摄，屋顶在图上相对地基向南偏西位移，每米高度约 0.63 米。因此图上量到的是屋顶轮廓，地面位置需按楼高反推。位移系数是用教学楼可见的北立面宽度对估计楼高标定的，没有独立标定，范围约 ±17%。
2. **所有楼高都是估计值。** 没有任何实测高度；层数来自视频画面，层高统一假定为 3.9 米。高度估错会连带影响地面位置：20 米高的楼，高度每错 1 米，位置约错 0.6 米。

`src/campus-data.js` 中每个条目的 `positionAccuracyM` 已把这两项不确定性合并进去（多数在 ±2 至 ±4 米）。

可信度分三类：**视频已证实**；**仅卫星图可见**（是否属于学校、作何用途未证实）；**单次读数，待复核**（东侧教学区的 18 个条目来自一个测量代理的单次读数，独立复核尚未完成）。

## 还没有、或不可靠的部分

- **推测的内容**。每个生成器文件（`src/world/builders/`、`src/world/extras/`）顶部都有一段说明，分开列出「参考里看得到的」和 ASSUMED（推测的）。主要的推测有：东侧教学楼的南侧外廊、全部教室布置和楼梯位置；西侧教学楼的北立面和楼内楼梯；体育馆的全部室内；看台和体育馆的所有尺寸（按视频画面比例估的，看台实物可能比模型高约一半）；弧形楼的北立面；板楼的南立面和圆塔的全部立面；战斗机的机型、朝向和升旗台的位置；校徽是按画面画的简化图形。
- **校名墙的高度**：视频显示校名高出北教学楼屋顶，据此把字墙画到 26.4 米；真实的墙是立在连接体上还是教学楼女儿墙上，没有查明。
- **新综合教学楼**的轮廓是单次读数，而且卫星图拍摄时这栋楼还没建成（原址是旧楼），所以轮廓只能当近似；它的 6 层来自规划文件，是本项目唯一有官方来源的层数。上面四层是封闭的，没有室内。
- **校园边界未确认**。南端建筑群、北区其余建筑、校门尚未入库；西北角的两块网球场和东北角的一块硬地球场是否属于学校不清楚。
- **独立复核没有完成**：原计划对东侧教学区、东南板楼、球场各做一次独立重测，因用量上限没有跑成，这些条目都是单次读数。
- **钟楼**位置是单次读数（±3.6 米），高度约 40 米是粗估。
- 教室、走廊没有任何参考资料，全部是推测；西侧教学楼和板楼的房间是封闭的，没有室内。

### 中途更正过的事实

- 跑道是标准 400 米（最初按卫星图误读为不足 400 米：南弯道在树影里）。
- 卫星图是斜拍的，最初量的屋顶轮廓被当成了地面轮廓，已全部校正。
- 看台座席是蓝、红、绿三段，不是全蓝（把 2022 年画面里的蓝色遮阳棚误认成了座席）。
- 西侧教学楼的玻璃楼梯塔在西端南侧，不在东端。

## 验证情况

以下均在无头浏览器（软件渲染）中验证，**没有在真实显卡或真实设备上测试过**：

- 行走与碰撞：10 个用例，预期值由数据文件推导。
- 教学楼：从地面进外廊、走楼梯上二层、穿过教室门进入教室（东侧两栋都测过）。
- 体育馆：从西侧两处门洞走进馆内。看台：整条是实心的，沿前墙的楼梯能走上走道；从走道到最高排的过道楼梯没有实走过。
- 「地点」菜单：11 个地面地点都落在预期高度的地面上，并能从那里继续行走。航拍模式：悬停、沿视线飞行、上升、下降、退出后落地。
- 界面：小地图、时间滑块、鼠标锁定与释放的流程、鼠标转向的处理逻辑。
- 手机触屏：在设备模拟下，推摇杆前进、右半屏滑动转向、松手停止。只在轻量场景下测得动，因为这里软件渲染全校园在手机像素密度下每秒不到一帧。

未能验证的：真实鼠标和 Esc 键、任何真机上的触屏、真实设备上的帧率。

已知现象：抗锯齿与阴影同时开启时，无头软件渲染环境的控制台会出现 4 条图形驱动的性能提示（`GPU stall due to ReadPixels`），不是错误。成因未查明，真实显卡上是否出现未测试。

## 校验用的网址参数

- `?view=top` 正上方俯视（北在上）；可加 `&w=&e=&n=&s=` 指定范围（米）
- `?view=overview` 斜俯视；可加 `&cx=&cy=&cz=&tx=&ty=&tz=` 指定相机位置与目标
- `?flat=1` 实体轮廓以纯色无阴影绘制
- `?time=15` 时刻（小时）；`?aa=0`、`?shadows=0` 关闭抗锯齿、阴影；`?quality=low|high` 画质；`?ui=0` 隐藏界面；`?only=编号,编号` 只生成指定建筑（同时略去绿化、球场等附加模块，加 `&extras=1` 保留）
